# Ferramenta-Impostos-de-Renda
Esta é uma ferramenta feita no Excel para auxiliar na declaração do imposto de renda. Ela tem um menu interativo lateral que permite transitar rapidamente entre as páginas, que são: 1) Dados do titular, 2) Informes de rendimentos bancários, e 3) Notas bancárias e extratos de holerites.
